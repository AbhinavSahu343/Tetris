# 🎮 Tetris Game

A classic **Tetris game built from scratch**, featuring the core mechanics of the original game with a clean and interactive gameplay experience.

## ✨ Features

* 🧩 Multiple Tetris pieces with rotation
* ⬇️ Smooth piece movement and dropping
* 🧹 Automatic line detection and clearing
* 🏆 Score tracking
* 📈 Increasing difficulty as the game progresses
* 💥 Game-over detection
* 🎮 Keyboard-based controls
* 🔄 Restart / replay functionality
* 🖥️ Simple and responsive game interface

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript

## 🎯 Objective

Arrange falling blocks to form complete horizontal lines. Completed lines are cleared, increasing your score. The game ends when the blocks reach the top of the board.

## 🚀 Getting Started

Clone the repository:

```bash
git clone <your-repository-url>
```

Open the project folder and launch `index.html` in your browser.
